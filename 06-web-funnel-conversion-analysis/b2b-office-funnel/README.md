# 🏢 Fastfive 웹 행동 데이터 분석을 통한 인원 규모별 퍼널(Funnel) 최적화 프로젝트

> **숫자의 '양'에 가려진 '질(Value)'을 발굴하다**
> 전체 평균 데이터의 착시를 깨고, 1인 소호 유저와 20인 이상 기업 고객의 재무 심리를 고려해 웹사이트 전환 퍼널을 이원화한 데이터 드리븐 기획 프로젝트입니다.

---

## 🛠️ Tech Stack & Methodology
* **Web Analytics:** Google Analytics 4 (GA4) Custom Event & Parameter Tracking
* **Data Processing & Indexing:** Google Sheets (Pivot Table, Index/Match, Dynamic Mapping)
* **Analysis Method:** 기간별(Before vs After), 기기별(PC vs Mobile), 세그먼트별(인원 구간 규모) 크로스 인덱싱 분석

---

## 1. 프로젝트 개요 (Overview)
* **배경:** 공유오피스 플랫폼의 마케팅 예산 집행 대비 대형 계약(다인 리드)의 정체 원인 파악 필요.
* **목적:** 웹사이트 내 GA4 이벤트 로그를 분석하여 이탈 구간을 정의하고, 리드 가치가 높은 기업형 고객을 록인(Lock-in)할 수 있는 UI/UX 및 전환 깔대기(Funnel) 개선안 도출.
* **주요 역할:** GA4 Raw 데이터 추출, 구글 시트 기반 데이터 가공/인덱싱, 세그먼트 분석 설계 및 최종 GNB UI 기획.

---

## 2. 데이터 가공 및 분석 (Data & Analysis)

### 📊 GA4 Event Raw Data 가공 방식
* GA4의 영역별(`GNB`, `LNB`), 기기별(`Mobile`, `Desktop`), 텍스트/이벤트 파라미터(`btnName`), 인원 구간 리드 데이터(`1-2인`, `3-9인`, `10-19인`, `20인이상`)를 추출.
* 구글 시트 상에서 개편 전(`Before: 1/1 ~ 2/13`)과 개편 후(`After: 2/14 ~ 3/31`) 데이터를 매핑하고, 다인 비중 및 소인 비중을 산출할 수 있도록 **다차원 크로스 인덱싱 테이블** 구현.

### 🚨 Aggregate Data의 오류: "평균의 함정"
기존 웹사이트 분석은 '전체 전환율', '전체 리드폼 오픈율' 등의 총량 지표만을 기준으로 최적화되어 있었습니다. 그러나 모수의 절대다수를 차지하는 1~2인 소호 유저의 데이터가 전체 지표를 왜곡하고 있음을 발견했습니다.

### 🔍 세그먼트 분리 분석 결과
유입 트래픽을 **소인 리드(1-2인)**와 **다인 리드(20인 이상)**로 최초 세그먼트화하여 분석한 결과, 명확한 행동 패턴의 차이가 드러났습니다.

* **PC vs Mobile 환경의 비대칭성**
  * PC 환경은 전환 유저의 **75.72%가 GNB를 클릭**할 만큼 탐색 관여도가 매우 높음.
  * 그러나 이전 GNB 개편(메뉴명 '상품 안내' $\rightarrow$ '오피스라인업' 변경 및 뎁스 복잡화) 이후 PC 환경의 GNB CTR이 오히려 감소하는 Leaking 발생.
* **콘텐츠 선호도의 양극화 (GA4 Event 클릭 수 분석)**
  * **1~2인 리드:** 단기 프로모션, 가성비 타임딜, 30초 계산기 등 가볍고 직관적인 '혜택' 페이지 중심 소비.
  * **20인 이상 리드:** 독립형오피스 프리미엄, 전층형 오피스, 인테리어, 사옥 구축 가이드 등 대형 공간 스펙 및 '신뢰성' 콘텐츠 중심 소비.

## 3. 핵심 인사이트 (Insights)

### 💡 "같은 비용, 다른 스케일" : 타겟별 재무 심리의 본질
두 세그먼트가 바라보는 '비용'에 대한 페인 포인트(Pain Point)는 차원이 다릅니다.

* **1인 기업: 매달 나가는 고정비(OPEX)의 싸움**
  * **심리:** 전기세, 수도세, 커피값 등 자잘한 지출을 아끼는 것이 최우선.
  * **적합한 퍼널:** Fast & Hook (가성비 메시지 배치 $\rightarrow$ 직각적인 리드폼 오픈 유도)
* **20인 이상 기업: 자금 유동성과 초기 투자비(CAPEX)의 싸움**
  * **심리:** 수천만~억 단위의 보증금 묶임, 인테리어 공사비 및 원상복구 리스크 등 비즈니스 기회비용 헤징이 최우선.
  * **적합한 퍼널:** Deep & Value (충분한 정보와 재무적 안전성 탐색 지원 $\rightarrow$ 맞춤 전문 컨설팅 유도)

> **결론:** 모수가 많다는 이유로 소인 리드에 맞춰진 '가성비 향' 퍼널에 대형 기업 고객(다인 리드)을 밀어 넣음으로써, **고가치 대형 계약 고객들을 웹사이트 초입에서 탈락시키는 구조적 문제**를 GA4 데이터로 증명했습니다.

## 4. 실행 조치 (Action & Implementation)

공급자 관점의 상품 나열을 버리고, 유저가 인원 규모에 따라 스스로를 대입할 수 있도록 **"사용자 여정(Customer Journey)의 이원화"** 전략을 실행했습니다.

### 🛠️ GNB 깔대기(Funnel) 재정렬 및 UI 개선
* **인원 기반 셀프 세그먼테이션(Self-Selection) 장치 마련**
  * GNB 내 다인 리드 타겟 메뉴(`독립형오피스 프리미엄`, `커스텀오피스`, `전층형오피스`) 옆에 **[20인이상 추천]** 태그를 직관적으로 노출.
  * 바쁜 기업 의사결정권자들의 탐색 피로도를 줄이고, 웹사이트 진입 레벨에서 올바른 깔대기를 타도록 동선 단축.
* **PC UX 탐색 흐름 복원**
  * PC 메인 메뉴명을 직관적인 워딩으로 복구하고 서브 메뉴 접근성을 개선하여, 끊어졌던 다인 리드의 탐색 흐름 연결.

```text
[기존 퍼널]  전체 데이터 최적화 ──> 소인 타겟 UI ──> 다인 리드(고가치 고객) 심리적 허들로 이탈
  
  ▼
  
[개선 퍼널]  GNB 세그먼트 가이딩 UI 적용 
               ├── 일반 오피스 / 프로모션 ──> 소인 타겟 (Fast-Track)
               └── 프리미엄 / 전층형 [20인이상 추천] 🔥 ──> 대형 기업 전용 맞춤 퍼널 (Deep-Track)
```

## 5. 성과 및 기대 효과 (Expected Impact)
* **체질 개선: 유입량(Volume) 위주의 마케팅 최적화에서 탈락하던 고가치 B2B 대형 리드 획득(Value) 중심의 최적화 체계 구축.

* **데이터 역량 입증: 고가의 외부 솔루션 없이 오직 GA4 Event와 구글 시트 다차원 매핑만으로 비즈니스 핵심 코어 지표를 개선할 수 있음을 증명.

* **의의: 마케팅 데이터 분석 시 전체 평균 지표의 왜곡을 방지하기 위한 '세그먼트 분석'의 중요성을 전사적으로 증명한 선례 정립.
