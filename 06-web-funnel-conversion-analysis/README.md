# 🎯 Clickstream Log Sequence & Web Funnel Conversion Path Analysis

본 프로젝트는 고도화된 매체 최적화 및 광고 데이터 인프라 구축에 이어, 서비스의 최종 터치포인트인 공식 홈페이지의 원천 웹 로그(Clickstream) 데이터를 추적 및 가공한 **그로스 엔지니어링 및 유저 행동 패턴 분석 프로젝트**입니다. 

단순히 툴(GA4 등)이 제공하는 정형화된 대시보드를 넘어, 원천 클릭스트림 로그를 SQL 및 파이썬 시퀀스 정렬 알고리즘을 통해 유저별 이동 경로를 복원하고 상품군별 첫 구매 전환 자산과 이탈 보틀넥(Bottleneck)을 완벽하게 규명했습니다.

---

## 🚀 Key Business Challenges

* **상품 카테고리별 전환 퍼널 차이 규명**: 시간권, 1일권, 기간권(무제한/주야간 패스) 등 상품 성격에 따라 유저가 첫 구매를 결정하기까지 거치는 필수 거점 페이지와 체류 시간의 차이 분석.
* **전환 리드타임(`convDuration`) 계량화**: 유입 최초 터치포인트 시점부터 실제 결제 타격 포인트까지의 비즈니스 리드타임을 산출하여, 타겟 리타겟팅 마케팅의 최적 CRM 시점 도출.
* **미구매 이탈 유저의 '데드엔드(Dead-end)' 포착**: 구매 전환 허들을 넘지 못하고 이탈하는 잠재 유저들이 최종적으로 머무는 이탈 페이지의 변곡점을 추출하여 UI/UX 개선 근거 마련.
* **프로모션 캘린더 연동 추이 분석**: 특정 기간 진행된 프로모션 매프레임 데이터와 일별 미구매/첫구매 유저 볼륨 트렌드를 결합하여 프로모션 기여 효과 검증.

---

## 🏗️ Clickstream Processing Pipeline & Architecture

웹 로그의 방대한 양과 불필요한 노이즈를 제어하기 위해 고안된 데이터 엔지니어링 파이프라인 구조입니다. AWS RDS 프로덕션 데이터의 결제 원장과 마케팅 데이터 마트의 페이지 뷰 로그를 결합하여 처리합니다.

```text
[AWS RDS Production DB] ──(SSH Tunnel Forwarder)──► [Python Preprocessing Engine]
                                                             │
 1. 노이즈 백아웃 (MainActivity, UIViewController, login, sign, order 스크리닝)
 2. 매체 분류 (Web vs App 디커플링 및 순수 웹 로그 필터링)
 3. 세션 시퀀싱 (groupby().cumcount() 활용 페이지 이동 순번 page_row_num 부여)
 4. 시간 델타 연산 (유저별 최초 진입 대비 최종 결제일 기준 convDuration 산출)
                                                             │
                                                             ▼
 [Google Sheets API (gspread)] ◄─── (자동화 마트 적재) ─── [Financial & Growth Data Mart]
```

## 🛠️ Data Engineering & Pipeline Core Logics

### 1. 노이즈 데이터 백아웃 및 유효 웹 로그 필터링 (Noise Cleaning)
앱 내 가상 뷰 컨트롤러나 회계 처리 단계에서 중복 발생하는 계정 가입/인증 페이지(`login`, `sign`, `client`, `order`) 및 디바이스 기본 액티비티 요소를 정규표현식 매칭 기법으로 과감히 백아웃 처리하여, 유저의 순수한 '콘텐츠 탐색 및 상품 탐색' 로그만 보존했습니다.

### 2. 파이썬 기반 유저 세션 시퀀싱 알고리즘 (Session Sequencing)
동일 유저의 불규칙한 이동 시계열 데이터를 보정하기 위해 `sort_values(['user_id_2', 'event_timestamp'])` 처리 후, 유저 세그먼트 내에서 유니크하게 페이지가 전환되는 지점만을 추적하여 이동 순번(`page_row_num`)과 조회 페이지 깊이(`row_num_page`)를 윈도우 함수 형태로 동적 할당했습니다.

### 3. 전환 소요 기간 및 경로 속성 연산
유저 그룹별 `event_time_kst`의 최댓값(Max)과 최솟값(Min)의 차이를 일단위로 묶어 `convDuration` 변수를 선언하고, 각 첫구매 코호트별로 가장 먼저 진입한 첫 페이지(`first_page`)와 최종 전환을 일으킨 마지막 페이지(`last_page`)를 `transform('first' / 'last')` 알고리즘으로 연결했습니다.

## 💡 Key Analytical Insights (보고서 요약)

### 1. 첫 구매 상품군별 전환 리드타임 (`convDuration`) 디커플링
* **시간권 및 1일권 (단발성 엔트리 상품군)**: 평균 전환 소요 기간이 매우 짧고 최초 유입 당일 또는 3일 이내에 최종 결제까지 이어지는 고속 퍼널 구조를 보였습니다. (중앙값 기준 0~1일)
* **기간권 무제한 패스 (고관여 구독 상품군)**: 최초 웹 탐색 이후 패스 상세 안내 페이지 및 지점 인프라 소개 페이지를 평균 4회 이상 교차 탐색하며, 최종 구매 의사결정까지 평균 9.8일의 숙려 기간을 거치는 장기 심사숙고형 패턴이 도출되었습니다.

### 2. 이탈 유저의 최종 데드엔드 페이지 분석 (Drop-off Bottleneck)
* 구매로 전환되지 않은 유저들의 이탈 로그 전수 집계 결과, 메인 홈 페이지(`fivespot.io/`)를 제외하면 특정 패스 안내 상세 페이지의 중단부와 가격 정책 안내 화면에서의 이탈률이 전체의 34.2%를 차지했습니다.
* 특히 최초 진입 시점(`page_row_num == 1`)의 첫 페이지가 가격 탭이었던 유자는 지점 인프라나 특장점을 먼저 본 유저 대비 이탈 확률이 약 2.5배 높게 나타나, 퍼포먼스 광고 랜딩 페이지를 단순 가격표가 아닌 공간 인프라 상세 콘텐츠로 변경해야 한다는 실무적 액션 아이템을 도출했습니다.

### 3. 일별 프로모션 스케줄 연동 효과
* 연말/연초 진행된 프로모션 타임라인을 매핑하여 일별 트렌드를 분석한 결과, 프로모션 유입 기간 동안 미구매 잠재 유저의 모객 볼륨은 평시 대비 2.2배 급증했으나, 해당 유저들의 `row_num_page`(페이지 탐색 깊이)는 오히려 낮게 측정되는 '단발성 체류 현상'을 발견했습니다. 이를 통해 단순 할인 프로모션의 양적 성장 이면에 숨겨진 질적 전환율 보완 대책 수립의 필요성을 제시했습니다.

## 📊 Downstream Integration (Data Governance)

분석 엔진의 말단 레이어에서는 가공 완료된 통계 리포트 매트릭스(`category_conv_stats`, `df_미구매유저_groupby` 등)를 의사결정권자(C-Level, 마케팅 디렉터)들이 즉시 모니터링할 수 있도록 구글 스프레드시트 API(`gspread`) 엔진과 연동했습니다.
전체 오버라이트(Overwrite Pattern) 멱등성을 보장하도록 설계되어 일별로 안전하게 갱신됩니다.
