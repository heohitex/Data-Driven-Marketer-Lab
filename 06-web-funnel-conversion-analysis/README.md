# 🎯 웹 로그 분석 기반 랜딩페이지 최적화 (디자이너·퍼블리셔 협업)

본 프로젝트는 약 18만 명의 구매 및 미구매 유저의 웹 이용 흐름(클릭스트림) 데이터를 정밀 분석하여 **유저 퍼널의 병목을 진단하고, 이를 해결하기 위해 타깃 페르소나별 맞춤형 랜딩페이지를 기획하여 최종 라이브 배포까지 완수한 데이터 기반 그로스(Growth) 프로젝트**입니다.

서드파티 툴이 주는 정형화된 대시보드를 넘어 파이썬으로 유저 시퀀싱 및 클래러티(Clarity) 툴로 클릭 행동을 직접 분석했으며, 데이터가 증명하는 유저의 진짜 페인포인트(비용 및 접근성 탐색 요구)를 바탕으로 기존의 단순 할인 프로모션 랜딩페이지를 **실질적 혜택과 설득 논리를 갖춘 페르소나 전용 프로덕트**로 전면 개편했습니다.

---

## 🚀 프로젝트 주요 과제

* **18만 명 기반 구매 전 경로 분석**: 유저가 처음 진입했을 때와 마지막으로 이탈했을 때의 페이지 전환율을 분석하여 최적의 랜딩 거점 페이지 선정.
* **유저 구매 숙려 기간 정량화**: 유입 후 최종 결제까지 걸리는 비즈니스 리드타임을 산출하여, 리타겟팅 마케팅의 정밀한 기준점 마련.
* **클래러티(Clarity) 기반 핵심 관심 콘텐츠 포착**: 클릭 히트맵 분석을 통해 유저가 화면 내에서 진짜 필요로 하는 정보(요금제, 지점 위치 등)의 우선순위 도출.
* **데이터 기반 스토리텔링 개편 및 배포**: 분석 결과를 근거로 와이어프레임을 도출, 디자이너·퍼블리셔와의 커뮤니케이션을 통해 라이브 배포 주도.

## 🛠️ 데이터 정제 및 가공 로직

### 1. 캠페인 일정 자동 익명화 (Promotion Masking)
일별 모객 트렌드와 전사 프로모션 일정 간의 연관성을 정밀하게 검증하기 위해, 날짜 범위를 인식하여 전용 캠페인 코드로 자동 치환하는 매핑 함수(`get_promotion_name`)를 구현했습니다. 사내 보안 가이드에 따라 실제 프로모션 명칭은 기술 플레이스홀더(`PROMOTION_TYPE_ALPHA` 등)로 익명화 처리되었습니다.

### 2. 불필요한 노이즈 로그 필터링 (Noise Cleaning)
계정 가입, 단순 로그인, 결제 도중 발생하는 시스템 페이지 등 마케팅 행동 분석과 무관한 중복 로그들을 정규표현식 매칭 기법으로 과감히 걷어내어 유저의 순수한 '공간 탐색 및 상품 조회' 로그만 보존했습니다.

### 3. 파이썬 기반 유저 행동 시퀀싱 알고리즘
유저별로 불규칙하게 쌓인 타임스탬프 데이터를 정렬한 뒤, 유저 세그먼트 내에서 페이지가 전환되는 지점만을 추적하여 이동 순번(`page_row_num`)과 조회 깊이(`row_num_page`)를 계산하는 로직을 구축했습니다.

## 💡 분석 결과 및 문제 진단 (As-Is 한계)

### 1. 진입 및 이탈 페이지 분석 결과
* **메인페이지의 압도적 효율**: 전체 상품군에서 처음 방문했을 때(`1st Click`)나 마지막으로 방문했을 때(`Last Click`) 모두 메인페이지의 전환 효율이 가장 우수했습니다. 
* **위클리 프로모션의 한계**: 위클리 페이지는 트래픽 비중이 낮음에도 불구하고 최초 진입 및 최종 클릭 전환율(3.5%) 모두 메인, 웰컴스팟 등 타 페이지 대비 떨어졌습니다. 유저들은 할인 스킴 보다는 "파이브스팟이 어떤 서비스인지" 본질을 더 궁금해하는 것으로 판단됩니다.
* **메인 배너 클릭률 급감**: 클릭 히트맵 스캔 결과 메인 배너 클릭 순위가 8위에서 18위로 폭락했으며(클릭률 3.15% -> 0.57%), 위클리 랜딩 배너는 0.1% 수준으로 유저들이 프로모션 콘텐츠 자체에 큰 반응을 보이지 않음을 확인했습니다.
* **특정 프로모션의 높은 이탈**: '1인가구 프로모션' 페이지는 미구매 유저가 마지막으로 본 페이지 전수 조사 결과 가장 높은 이탈률이 발생하여 OFF 조치를 제안했습니다.

### 2. 유저 구매 숙려 기간 분석
* 극단적인 롱테일 유저(100일 이상)로 인해 평균값은 10일로 계산되었으나, **실제 구매 숙려 기간의 중앙값(Median)은 0~1일**로 유입 당일 매우 빠르게 구매를 결정하는 특성을 보였습니다.
* 데이터 누적 기준 7일 이내에 무제한패스 구매자의 76%, 시간패스 구매자의 87%, 주말야간 및 일일권 구매자의 80% 이상이 결제 타격을 완료함을 증명했습니다.

### 3. 클래러티(Clarity) 툴 기반 콘텐츠 관심도 확인
* 유저들이 가장 많이 관심을 보이고 상호작용하는 레이아웃은 **[최상단 CTA > 지점 위치 찾기 CTA > 타 서비스와의 비용 비교 및 요금제 상품 안내]** 순으로 일관되게 나타났습니다.
* 서비스 이용자인 프리랜서, 1인 사업자, 직장인들의 페인포인트는 단순히 '집중이 잘 안 된다'거나 '공간 퀄리티' 같은 부가적 요소가 아니며, 실질적인 비용 장벽과 접근성이 핵심 세일즈 포인트임을 포착했습니다.

## 🎨 데이터 기반 랜딩페이지 개편 및 배포 (To-Be)

분석 결과를 바탕으로 기존의 **"프로모션 할인 압박 ➡️ 유저가 스스로 탐색하며 서비스 이해하기"** 구조를 **"랜딩 최상단에서 실질적 베네핏 설명 ➡️ 논리적 설득 ➡️ 행동 유도"** 패러다임으로 전환했습니다. 또한, 공간 자체의 이점보다 페르소나별로 철저히 다르게 와이어프레임을 설계하여 배포했습니다.

| 타깃 세그먼트 | 데이터 기반 핵심 페인포인트 및 가설 | **실제 배포된 To-Be 화면 반영 내용** |
| :--- | :--- | :--- |
| **1인 사업자**<br>(수요 명확 그룹) | "공간이 좋으면 돈을 번다"는 감성적 접근은 설득력이 낮음.<br>→ **"돈을 확실히 아낄 수 있는데, 퀄리티까지 챙길 수 있다"**는 논리적 비용 접근 필요. | 한국부동산원 공신력 데이터를 활용하여 강남 1인 사무실 임대 비용(NOC) 대비 파이브스팟 이용 시 연간 절감되는 구체적 금액 지표 시각화 배치. |
| **프리랜서**<br>(수요 명확 그룹) | 스터디카페와의 단순 가격 경쟁은 브랜드 자산 낭비.<br>→ **이동 효율성과 압도적 접근성** 강조 필요. | 내가 평소 카페에 쓰던 비용 수준으로 서울 전역 250여 개 지점 카페보다 더 쾌적한 인프라를 무제한 교차 이용할 수 있다는 장점 극대화 소구. |
| **직장인 & 취준생**<br>(잠재 수요 그룹) | 공간의 필요성을 아직 크게 못 느끼는 미수요 층.<br>→ **갓생 유도 및 FOMO(소외감) 자극** 필요. | 타 서비스 대비 압도적인 공간 퀄리티를 보여줌과 동시에, 커피 한 잔 값(2천 원대)으로 이용 가능한 주말·야간패스 가격 혜택을 푸시하여 즉각적인 행동 변화 유도. |

## 📈 추후 최적화 실험 계획 (A/B 테스트 로드맵)

신규 랜딩페이지 배포 이후, 누적되는 유입 트렌드에 맞추어 카피라이팅 최적화 실험을 신속하게 전개할 수 있도록 기획 단계에서부터 구조를 분리했습니다.

![Landing Page Structure](./06-web-funnel-conversion-analysis/ab-testing-framework.png)

* **가변 영역 (1~2번 섹션)**:
  * 초반 이탈률 2.5배 개선을 목적으로 유저 타깃 유형에 따라 상단 히어로 카피(비용 절감형, 접근성 강조형, 감성/FOMO 자극형)를 유연하게 교체 실험해 볼 수 있는 영역입니다.
* **고정 영역 (3~6번 섹션)**:
  * 지점 위치, 세부 스펙, 유저 후기 등 통제 변수로 작용할 기본 정보 블록입니다. 상단 가변 영역의 메시지 변화에 따른 순수 전환율(CVR) 영향도만을 정확하게 비교 트래킹하기 위해 대조군으로 고정해 두었습니다.
