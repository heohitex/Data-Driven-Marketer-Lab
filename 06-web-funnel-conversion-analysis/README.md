# 🎯 Clickstream Log Sequencing & Data-Driven Landing Page Optimization (CRO)

본 프로젝트는 고도화된 마케팅 인프라 구축에 이어, 최말단 터치포인트인 공식 홈페이지의 원천 웹 로그(Clickstream) 데이터를 시퀀싱하여 **유저 퍼널의 병목을 진단하고, 이를 기반으로 랜딩페이지를 직접 A/B 테스트 규격으로 기획 및 재설계한 완전한 데이터 기반 그로스(Growth) 프로젝트**입니다.

정형화된 대시보드를 넘어, 원천 클릭스트림 로그 분석 결과 도출된 **"가격 우선 탐색 유저의 높은 이탈률(2.5배)"** 리스크를 해결하기 위해 페르소나 및 인프라 중심의 신규 랜딩페이지 프로토타입을 직접 기획했습니다.

---

## 🚀 Key Business Challenges

* **상품 카테고리별 전환 퍼널 차이 규명**: 시간권, 1일권, 기간권 등 상품 성격에 따라 유저가 첫 구매를 결정하기까지 거치는 필수 거점 페이지와 체류 시간의 차이 분석.
* **전환 리드타임(`convDuration`) 계량화**: 최초 진입 시점부터 결제 타격 포인트까지의 리드타임을 산출하여, 리타겟팅 CRM 마케팅의 최적 최적화 타이밍 도출.
* **이탈 유저의 '데드엔드(Dead-end)' 포착**: 구매 전환 허들을 넘지 못하고 이탈하는 유저들이 최종적으로 머무는 이탈 페이지의 변곡점을 추출하여 UI/UX 개선 근거 마련.
* **인사이트 기반의 CRO 액션**: 데이터 분석 결과를 실제 마케팅 전략과 기획안으로 치환하여 비즈니스 전환율(CVR)의 직접적인 상승 루프 마련.

---

## 🏗️ Clickstream Processing Pipeline & Architecture

```text
[AWS RDS Production DB] ──(SSH Tunnel Forwarder)──► [Python Preprocessing Engine]
                                                             │
 1. 노이즈 백아웃 (MainActivity, UIViewController, login, sign, order 스크리닝)
 2. 매체 분류 (Web vs App 디커플링 및 순수 웹 로그 필터링)
 3. 세션 시퀀싱 (groupby().cumcount() 활용 페이지 이동 순번 page_row_num 부여)
 4. 시간 델타 연산 (유저별 최초 진입 대비 최종 결제일 기준 convDuration 산출)
                                                             │
                                                             ▼
 [Growth Insight Extraction] ──────────────────────► [Action: Landing Page Redesign (CRO)]
```

## 🛠️ Data Engineering & Pipeline Core Logics

### 1. 노이즈 데이터 백아웃 및 유효 웹 로그 필터링
앱 내 가상 뷰 컨트롤러나 회계 처리 단계에서 중복 발생하는 계정 가입/인증 페이지(`login`, `sign`, `client`, `order`) 및 디바이스 기본 액티비티 요소를 정규표현식 매칭 기법으로 과감히 백아웃 처리하여, 유저의 순수한 '콘텐츠 및 상품 탐색' 로그만 보존했습니다.

### 2. 파이썬 기반 유저 세션 시퀀싱 알고리즘
동일 유저의 불규칙한 이동 시계열 데이터를 보정하기 위해 `sort_values(['user_id_2', 'event_timestamp'])` 처리 후, 유저 세그먼트 내에서 유니크하게 페이지가 전환되는 지점만을 추적하여 이동 순번(`page_row_num`)과 조회 페이지 깊이(`row_num_page`)를 윈도우 함수 형태로 동적 할당했습니다.

### 3. 전환 소요 기간 및 경로 속성 연산
유저 그룹별 `event_time_kst`의 최댓값(Max)과 최솟값(Min)의 차이를 일단위로 묶어 `convDuration` 변수를 선언하고, 각 첫구매 코호트별로 가장 먼저 진입한 첫 페이지(`first_page`)와 최종 전환을 일으킨 마지막 페이지(`last_page`)를 `transform()` 알고리즘으로 연결했습니다.

## 💡 Key Analytical Insights & CRO Action Item

### 1. 데이터 분석 결과 요약 (Data Insight)
* **가격 선진입 유저의 치명적인 이탈**: 최초 진입 시점(`page_row_num == 1`)에 가격 정책/패스 안내 탭을 먼저 본 유저는 지점 인프라 콘텐츠나 페르소나 맞춤형 상세 페이지를 먼저 탐색한 유저 대비 **최종 이탈 확률이 약 2.5배** 높게 나타났습니다.
* **할인 프로모션의 한계**: 연말/연초 프로모션 스케줄 매핑 결과, 가격 할인 중심의 모객은 모객 볼륨은 평시 대비 2.2배 급증시켰으나 유저들의 페이지 탐색 깊이(`row_num_page`)를 낮춰 단발성 체류 후 이탈하는 체리피커 성향을 가중시켰습니다.

### 2. 인사이트 기반 랜딩페이지 최적화 설계 (CRO Action)
분석 결과를 바탕으로 **"가격 소구 위주에서 페르소나/공간 인프라 소구"**로 패러다임을 전환한 신규 랜딩페이지 프로토타입을 기획 및 설계했습니다.

| 분석 데이터 기반 진단 (As-Is 블록) | 행동 로그 기반 재설계 (To-Be 블록) | 기획 및 크리에이티브 반영 로직 |
| :--- | :--- | :--- |
| **가격 및 할인 직진형 레이아웃**<br>`"월 10만원대부터!", "최저가 보장 위크"`<br>→ 가격 필터링으로 인한 초반 이탈 유도 | **페르소나 가치 제안 우선 배치**<br>`"1인 기업이 성장에만 집중할 수 있도록"`<br>→ 핵심 타깃(1인 기업/프리랜서) 목적성 일치로 이탈 방지 | 유저 진입 첫 섹션에서 가격 허들을 지우고, 공간을 필요로 하는 근본적 유즈케이스와 공감대 형성 |
| **단순 매체 나열 및 텍스트 안내**<br>→ 공간 인프라 탐색 깊이 저하 및 체류 시간 감소 보틀넥 발생 | **공간 레이아웃 및 거점 시각화**<br>`주요 핵심 거점(강남, 광화문 등) 및 내부 인프라 모듈(업무 가구, 스낵 바 등) 전면 배치` | 유저가 직접 가보지 않아도 공간 퀄리티를 인지하게 하여 **페이지 탐색 깊이(`row_num_page`) 200% 개선 유도** |
| **쿠폰 다운로드 및 복잡한 정산 유도**<br>→ 결제 직전 심리적 저항 유발 | **핵심 저항 요인 선제적 해소(Friction Reduction)**<br>`"보존금 눈치에서 벗어났습니다. 0원"` | 가격 변동성에 저항을 느끼는 잠재 유저의 심리적 장벽인 '보증금/관리비' 체계를 0원으로 선언하여 최종 전환 훅 강화 |

## 📊 Downstream Integration (Data Governance)

분석 엔진의 말단 레이어에서는 가공 완료된 통계 리포트 매트릭스(`category_conv_stats`, `df_미구매유저_groupby` 등)를 의사결정권자(C-Level, 마케팅 디렉터)들이 즉시 모니터링하고 실무에 반영할 수 있도록 **구글 스프레드시트 API(`gspread`) 엔진과 연동**했습니다. 
전체 오버라이트(Overwrite Pattern) 멱등성을 보장하도록 설계되어 일별로 안전하게 갱신됩니다.
