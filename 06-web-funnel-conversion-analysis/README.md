# 🎯 Clickstream Log Sequencing & Data-Driven Landing Page Implementation (Deployed)

본 프로젝트는 고도화된 마케팅 인프라 구축에 이어, 서비스의 최종 터치포인트인 공식 홈페이지의 원천 웹 로그(Clickstream) 데이터를 시퀀싱하여 **유저 퍼널의 병목을 진단하고, 이를 기반으로 라이브 랜딩페이지를 직접 구현 및 성공적으로 배포(Deployment)까지 완료한 완전한 데이터 기반 그로스(Growth) 프로젝트**입니다.

사내 보안 가이드라인 준수 및 가독성을 위해 데이터 수집(Sourcing) 인프라 레이어는 추상화하였으며, 원천 로그 분석 결과 도출된 **"가격 우선 탐색 유저의 높은 이탈률(2.5배)"** 리스크를 비즈니스 관점에서 해결하기 위해 페르소나 및 인프라 중심의 신규 랜딩페이지를 **직접 기획하고 성공적으로 배포**했습니다.

---

## 🚀 Key Business Challenges

* **상품 카테고리별 전환 퍼널 차이 규명**: 시간권, 1일권, 기간권 등 상품 성격에 따라 유저가 첫 구매를 결정하기까지 거치는 필수 거점 페이지와 체류 시간의 차이 분석.
* **전환 리드타임(`convDuration`) 계량화**: 최초 진입 시점부터 결제 타격 포인트까지의 리드타임을 산출하여, 리타겟팅 CRM 마케팅의 최적 CRM 타이밍 도출.
* **미구매 이탈 유저의 '데드엔드(Dead-end)' 포착**: 구매 전환 허들을 넘지 못하고 이탈하는 잠재 유저들이 최종적으로 머무는 이탈 페이지의 변곡점을 추출하여 UI/UX 개선 근거 마련.
* **데이터 인사이트 기반의 최종 프로덕트 배포 (CRO Action)**: 분석 데이터를 실제 비즈니스 가치로 전환하는 최적화된 최종 라이브 랜딩페이지를 **직접 구현 및 배포**하여 전환율(CVR)의 직접적인 상승 유도.

---

## 🛠️ Data Engineering & Pipeline Core Logics

### 1. 캠페인 캘린더 타임라인 익명화 (Promotion Timeline Masking)
실제 진행된 전사 프로모션 타임라인 스케줄과 일별 미구매/첫구매 유저 볼륨 트렌드를 결합하여 프로모션 기여 효과를 정밀하게 검증하기 위해, 일별 날짜 범위를 인식하여 전용 캠페인 코드로 자동 치환하는 분기 매핑 함수(`get_promotion_name`)를 구현했습니다. 사내 대외비 항목 보호를 위해 실제 프로모션 명칭은 글로벌 표준 기술 플레이스홀더(`PROMOTION_TYPE_ALPHA` 등)로 안전하게 익명화 처리되었습니다.

### 2. 노이즈 데이터 백아웃 및 유효 웹 로그 필터링 (Noise Cleaning)
앱 내 가상 뷰 컨트롤러나 회계 처리 단계에서 중복 발생하는 계정 가입/인증 페이지(`login`, `sign`, `client`, `order`) 및 디바이스 기본 액티비티 요소를 정규표현식 매칭 기법으로 과감히 백아웃 처리하여, 유저의 순수한 '콘텐츠 및 상품 탐색' 로그만 보존했습니다.

### 3. 파이썬 기반 유저 세션 시퀀싱 알고리즘 (Clickstream Sequencing)
동일 유저의 불규칙한 이동 시계열 데이터를 보정하기 위해 `sort_values(['user_id_2', 'event_timestamp'])` 처리 후, 유저 세그먼트 내에서 유니크하게 페이지가 전환되는 지점만을 추적하여 이동 순번(`page_row_num`)과 조회 페이지 깊이(`row_num_page`)를 윈도우 함수 형태로 동적 할당했습니다.

### 4. 전환 소요 기간 및 경로 속성 연산
유저 그룹별 최초 진입 시점 대비 실제 결제 타격 시점 간의 시차(Timedelta)를 계산하여 숙려 기간 변수(`convDuration`)를 선언하고, 각 첫구매 코호트별로 가장 먼저 진입한 첫 페이지(`first_page`)와 최종 전환을 일으킨 마지막 페이지(`last_page`)를 `transform()` 알고리즘으로 연결했습니다.

## 💡 Key Analytical Insights & Deployed CRO Action

### 1. 데이터 분석 결과 요약 (Data Insight)
* **가격 선진입 유저의 치명적인 이탈**: 최초 진입 시점(`page_row_num == 1`)에 가격 정책/패스 안내 탭을 먼저 본 유저는 지점 인프라 콘텐츠나 페르소나 맞춤형 상세 페이지를 먼저 탐색한 유저 대비 **최종 이탈 확률이 약 2.5배** 높게 나타났습니다.
* **할인 프로모션의 한계**: 연말/연초 프로모션 스케줄 매핑 결과, 가격 할인 중심의 모객은 모객 볼륨은 평시 대비 2.2배 급증시켰으나 유저들의 페이지 탐색 깊이(`row_num_page`)를 낮춰 단발성 체류 후 이탈하는 체리피커 성향을 가중시켰습니다.

### 2. 인사이트 기반 랜딩페이지 구현 및 배포 완료 (Deployed As-Is/To-Be)
분석 결과를 바탕으로 **"가격 소구 위주에서 페르소나/공간 인프라 소구"**로 패러다임을 전환한 신규 랜딩페이지를 직접 구현 및 라이브 배포했습니다.

| 비즈니스 진단 (As-Is 블록) | **최적화 배포 완료 (Deployed To-Be)** | 배포 및 크리에이티브 반영 로직 |
| :--- | :--- | :--- |
| **가격 및 할인 직진형 레이아웃**<br>`"월 10만원대부터!", "최저가 보장 위크"`<br>→ 가격 필터링으로 인한 초반 이탈 유도 | **페르소나 중심 공감형 헤드라인**<br>`"1인 대표를 위한 멤버십 추천 - 파이브스팟"`<br>→ 핵심 타깃(1인 기업/프리랜서) 목적성 일치로 이탈 방지 | 데이터 분석 기반으로 유저 진입 첫 섹션의 **가격 허들을 완전 제거**하고, 1인 기업 페르소나와의 공감대를 형성하여 초반 이탈률 2.5배 개선 목표 달성. |
| **단순 매체 나열 및 텍스트 안내**<br>→ 공간 인프라 탐색 깊이 저하 및 체류 시간 감소 보틀넥 발생 | **공간 퀄리티 및 거점 시각화**<br>`주요 핵심 거점(강남, 광화문 등) 및 내부 인프라 모듈(업무 가구, 스낵 바 등) 전면 배치` | 유저가 직접 가보지 않아도 공간의 퀄리티와 주요 지점의 위치를 직관적으로 인지하게 하여 **페이지 탐색 깊이(`row_num_page`) 개선 유도** |
| **쿠폰 다운로드 및 복잡한 정산 유도**<br>→ 결제 직전 심리적 저항 유발 | **핵심 저항 요인 선제적 제거**<br>`"보증금 눈치에서 벗어났습니다. 0원"` | 가격 변동성과 초기 비용에 저항을 느끼는 잠재 유저의 심리적 장벽인 '보증금/관리비' 체계를 0원으로 선언하여 **최종 전환율(CVR) 상승 유도** |
