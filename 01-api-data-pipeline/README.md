# 📊 파이브스팟 다채널 기여도 분석(MTA) 및 마케팅 자동화 파이프라인

패스트파이브 신사업 '파이브스팟'의 마케팅 ROI 최적화를 위해 멀티 클라우드(AWS RDS, GCP BigQuery) 데이터와 광고 매체 API를 결합한 **MTA 자동화 시스템**입니다. 

마케팅 성과 분석 및 전략적 의사결정 보고에 활용되며, 기존 Last-Click 방식의 성과 왜곡을 제거하고 실제 매출 트렌드와 **97.2% 일치하는 마케팅 공헌이익 데이터**를 제공합니다.

---

## 🚀 프로젝트 주요 과제

* **유입 채널 추적 누수 해결**: 분리되어 있던 DB 결제 데이터와 GA4 웹 행동 로그를 고유 식별자로 결합하여 마케팅 사각지대 제거.
* **MTA 성과 측정 왜곡 극복**: Last-Click 분석의 한계를 극복하고 주요 의사결정 보고 시 광고비 대비 실질 수익성(공헌이익)을 정밀 산출.
* **CRM 및 리포트 공수 자동화**: 매체별 성과 취합, 정산 리포트 작성, 타깃 고객 추출 및 알림톡 발송 전 과정 자동화.

---

## 🏗️ 시스템 아키텍처

![Data Pipeline Architecture](./data-pipeline.jpg)

### 1. Data Ingestion (마케팅 데이터 수집)
* **AWS Database**: 인터넷이 차단된 보안망 내 RDS에서 `SSH 터널링` 기반으로 파이브스팟 결제 원장 및 유저 마스터 데이터 추출.
* **Google BigQuery**: 구글 태그 매니저(GTM)로 맞춤 수집된 고정밀 웹 행동 로그(GA4 Raw Data) 적재.
* **Ad Platform APIs**: 네이버, 카카오, Meta, Google Ads API 연동을 통해 광고 집행 비용 데이터 동기화.

### 2. Processing & Modeling (MTA 및 마케팅 공헌이익 연산)
* **데이터 기반 MTA 모델링**: 7일 분석 기간(Lookback Window) 기준으로 고객 여정을 추적하여 First-Click, Last-Click, Linear 기여도를 소재 레벨까지 계산.
* **마케팅 공헌이익 분석**: 매체 광고비와 실제 매출 데이터를 매핑하여 매출 트렌드와 **97.2% 일치하는 공헌이익 지표** 산출 (의사결정 보고용 신뢰도 확보).
* **CRM 타깃 세그먼테이션**: 구매 여정 및 유저 데이터를 기반으로 푸시 마케팅이 필요한 타깃 유저 리스트 추출.

### 3. Activation & Reporting (최종 활용 및 CRM 자동화)
* **의사결정 BI 연동**: 빅쿼리 연산 결과를 구글 스프레드시트 및 `Tableau` 대시보드로 연동하여 주요 성과 보고 체계 마련.
* **CRM 마케팅 자동화 파이프라인**: 추출된 타깃 데이터를 `Python ➡️ Google Sheets ➡️ Zapier` 허브를 거쳐 `Solapi(솔라피)` API로 전달하여 알림톡 자동 발송 시스템 구축.

## 🚀 비즈니스 임팩트 및 성과

* **의사결정 데이터 신뢰도 확보**: 실제 매출 트렌드와 97.2% 일치하는 마케팅 수익성 데이터를 구현하여 보고 및 전략 수립 시 마케팅 예산 효율을 정량적으로 증명.
* **MTA 모델 기반 예산 최적화**: 멀티 터치 기여도 분석을 통해 신규 유입 및 인지에 기여한 숨은 매체와 크리에이티브 소재를 재발굴하여 마케팅 효율 극대화.
* **운영 공수 제로화**: 데이터 추출, 정산, 시각화, CRM 발송까지 이어지는 수동 업무를 100% 자동화하여 리소스 절감.
