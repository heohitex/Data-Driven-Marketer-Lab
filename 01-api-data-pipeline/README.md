# 📊 통합 마케팅 데이터 파이프라인 및 다채널 기여도 분석(MTA) 모델링

본 프로젝트는 여러 클라우드(AWS RDS 결제/유저 데이터베이스, GCP BigQuery 웹 로그)에 파편화되어 있던 데이터를 하나로 통합하고, 다채널 광고 캠페인의 실질적인 기여도를 정밀하게 측정하기 위한 **멀티 터치 기여도 분석(MTA) 모델 및 자동화 파이프라인 구축 프로젝트**입니다.

기존의 단순 '마지막 클릭(Last-Click)' 성과 측정 방식에서 벗어나, 고객 여정 초기 단계에서 브랜드를 인지시킨 광고 소재의 가치까지 정량적으로 평가할 수 있는 의사결정 체계를 마련했습니다.

---

## 🚀 프로젝트 주요 과제

* **데이터 단절 해소**: 구매 원장 데이터와 광고 유입 경로(행동 로그) 데이터가 분리되어 있어 발생하던 유입 채널 추적 누수 문제 해결.
* **성과 측정 왜곡 극복**: 고객 여정의 최종 단계(라스트 클릭) 매체만 과대평가되고, 유저를 처음 데려온 매체(퍼스트 클릭)는 과소평가되는 성과 측정의 사각지대 제거.
* **수동 정산 리포트 자동화**: 매일 아침 여러 매체와 툴을 오가며 수동으로 수집하던 일일 성과 및 데이터 마트 적재 프로세스 전면 자동화.

---

## 🛠️ 핵심 데이터 모델링 및 구현 내용

### 1. 보안을 고려한 멀티 클라우드 데이터 통합
* **안전한 데이터 추출**: 보안이 강화된 AWS 폐쇄망(VPC) 환경 내 결제 데이터베이스에 안전하게 접근하기 위해 보안 터널링 기법을 적용한 데이터 추출 로직을 직접 구현했습니다.
* **고객 행동 여정 통합**: 여러 기기와 브라우저를 넘나드는 유저의 파편화된 행동 로그를 하나의 고유 식별자로 매핑하여, 광고 클릭부터 최종 결제까지의 옴니채널 고객 여정 데이터 마트를 구축했습니다.

### 2. 다채널 기여도 분석(MTA) 모델 설계
* **7일 분석 기간(Lookback Window) 설정**: 무의미하게 긴 유입 데이터 정보를 배제하고, 실제 구매 숙려 기간 데이터를 기반으로 결제 전 7일간의 유효한 터치포인트만 필터링하여 데이터 신뢰도를 높였습니다.
* **다중 분석 모델 구현 및 비교**:
  * **마지막 클릭 (Last Click)**: 최종 전환에 직접적인 영향을 준 매체 분석 (단기 성과 타격용).
  * **처음 클릭 (First Click)**: 브랜드 인지 및 최초 신규 유입을 견인한 매체 분석 (확장성 캠페인 평가용).
  * **선형 배분 (Linear Attribution)**: 고객 여정에 참여한 모든 터치포인트와 광고 소재에 기여도를 균등 배분하여 장기 보조 지표로 활용.

### 3. 정규표현식 기반 매체 자동 매핑
* 마케팅 현장에서 복잡하게 얽혀 유입되는 다양한 UTM 파라미터와 소스 데이터를 규칙에 따라 비즈니스 채널 유형(NaverSA, Meta/Instagram, CRM, Organic 등)으로 정밀하게 자동 분류하는 정규표현식(Regex) 매핑 로직을 설계했습니다.

## 🚀 비즈니스 임팩트 및 성과

* **데이터 단일 진실 공급원(SSOT) 확보**: 매체 대시보드마다 숫자가 달라 혼선을 빚던 문제를 해결하고, 전사 마케팅 부서가 동일한 기준으로 성과를 바라볼 수 있는 통합 데이터 기준점을 수립했습니다.
* **마케팅 예산 효율 최적화**: 기여도 분석 모델을 통해 숨겨져 있던 '신규 유저 유입 기여 매체'를 재발굴하여, 성과가 없다고 판단되어 종료될 뻔한 핵심 캠페인의 예산을 유지 및 증액하는 데이터 근거를 제공했습니다.
* **운영 리소스 대폭 절감**: 매일 반복되던 일일 성과 데이터 취합 및 정산 업무를 100% 자동화 파이프라인으로 전환하여 마케팅 팀의 운영 공수를 줄이고 핵심 기획에 집중할 수 있는 환경을 조성했습니다.
