# 🏗️ 마케팅 데이터 파이프라인 및 수익 정합성·MTA 모델링 시스템

본 프로젝트는 멀티 클라우드(AWS RDS 결제 원장, GCP BigQuery 웹 로그) 및 주요 광고 매체 API 데이터를 안전하게 통합하고, GCP Vertex AI를 거점으로 비즈니스 핵심 지표를 산출하는 **엔드투엔드(End-to-End) 마케팅 데이터 파이프라인 구축 프로젝트**입니다.

다채널 기여도 분석(MTA) 모델 구현뿐만 아니라, 재무 장부와 **97.2% 일치하는 일일 공헌이익 분석 엔진** 및 뒷단의 **CRM 자동화 파이프라인(Solapi 연동)**까지 연계하여 전사 의사결정의 단일 진실 공급원(SSOT)을 구축했습니다.

---

## 🚀 프로젝트 주요 과제

* **데이터 파편화 및 추적 단절 해소**: 데이터베이스에 분리되어 있던 결제 원장 정보와 GA4 웹 행동 로그 데이터를 고유 식별자 기반으로 매핑하여 유입 경로 추적 사각지대 제거.
* **회계 매출 정합성 및 성과 왜곡 극복**: Last-Click 방식 의사결정으로 인한 초기 인지 매체 과소평가 문제를 해결하고, 매달 정산 시점의 재무 매출과 일일 마케팅 대시보드 간의 데이터 격차 해소.
* **풀 마케팅 자동화(Ad-Tech & CRM)**: 매일 반복되는 매체별 성과 취합, 정산 리포트 작성, 타깃 고객 추출 및 푸시 발송 업무의 전 과정 자동화.

---

## 🏗️ 시스템 아키텍처

![Data Pipeline Architecture](./data-pipeline.jpg)

### 1. Data Sources & Ingestion (데이터 수집 레이어)
* **AWS Database**: 인터넷 연결이 차단된 AWS 보안망 내 RDS에서 `SSH 터널링` 기법을 통해 결제 원장 및 유저 마스터 데이터 추출.
* **Google BigQuery**: 구글 태그 매니저(GTM)를 통해 수집된 고정밀 웹 행동 로그(GA4 Raw Data) 적재.
* **Ad Platform APIs**: 네이버, 카카오, Meta, Google Ads의 API 규격을 활용하여 `OAuth 2.0` 기반으로 광고 집행 비용 데이터 동기화.

### 2. Processing & Modeling (GCP Vertex AI 거점 연산 레이어)
* **수익 인식 엔진 (Accounting Revenue Recognition Engine)**: 파이썬 스크립팅 기반의 스케줄링 허브를 구축하여, 일별 발생 매출 데이터를 재무 회계 기준에 부합하도록 자동 계산.
* **공헌이익 및 수익성 분석 (Profitability Analysis)**: 매체 API의 광고비 데이터와 AWS의 매출 데이터를 실시간 조인하여 **97.2%의 높은 정합성을 가진 일일 공헌이익 지표** 산출.
* **데이터 기반 MTA 모델링**: 7일 분석 기간(Lookback Window)을 기준으로 고객 여정을 추적하여, First-Click(최초 인지), Last-Click(최종 전환), Linear(선형 배분) 기여도를 매체 및 소재(Creative) 레벨까지 계산.
* **CRM 타깃 세그먼테이션**: 구매 여정 및 유저 마스터 데이터를 기반으로 즉각적인 마케팅 액션이 필요한 타깃 유저 리스트 추출.

### 3. Activation & Reporting (최종 활용 및 자동화 레이어)
* **데이터 시각화 (BI)**: 빅쿼리 연산 결과를 구글 스프레드시트 및 `Tableau` 대시보드로 연동하여 소재별 On/Off 의사결정이 가능한 시각화 환경 제공.
* **매체 최적화 자동화**: 가공된 고정밀 구매 이벤트를 매체 서버로 직접 전송(S2S Conversion)하고 맞춤 타깃(Custom Audience)을 자동 동기화.
* **CRM 마케팅 자동화 파이프라인**: 추출된 타깃 세그먼트 데이터를 `Python ➡️ Google Sheets ➡️ Zapier` 허브를 거쳐 `Solapi(솔라피)` API로 전달하여 알림톡 및 LMS가 자동으로 발송되는 시스템 구축.

## 🚀 비즈니스 임팩트 및 성과

* **의사결정 신뢰도 극대화**: 전사 마케팅 예산 집행의 기준이 되는 데이터 정합성을 97.2%까지 끌어올려 데이터 기반의 단일 의사결정 체계(SSOT) 수립.
* **마케팅 효율 및 성과 사각지대 제거**: 멀티 터치 기여도(MTA) 분석을 통해 신규 유입 및 인지에 기여한 숨은 매체를 발굴하고 예산 분배 효율 최적화.
* **운영 공수 제로화**: 데이터 추출, 정산, 시각화, CRM 발송까지 이어지는 수동 업무 파이프라인을 100% 자동화하여 리소스 절감 및 기획 집중도 향상.
