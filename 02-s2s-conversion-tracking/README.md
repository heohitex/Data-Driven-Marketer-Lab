# 📡 서버 간 데이터 연동(CAPI)을 통한 광고 최적화 시스템 고도화

본 프로젝트는 결제 발생 시 실시간으로 구매 데이터를 수집하고, 데이터베이스(AWS RDS) 및 로그 저장소(GCP BigQuery)에 흩어진 유저 식별 정보와 결제 데이터를 결합하여 주요 광고 매체(Meta, Google, Kakao) 서버로 직접 전송하는 **안정적인 데이터 송신 파이프라인 구축 프로젝트**입니다.

브라우저 쿠키 제한 환경을 우회하는 서버 간 직접 연동 방식을 고도화하여, Meta 광고 관리자 기준 **구매 이벤트 매칭 품질(EMQ) 점수를 기존 5.6점에서 현재 8.1점(우수)까지 상향**시켰으며 광고 최적화 효율을 극대화했습니다.

---

## 🚀 프로젝트 주요 과제

* **웹 트래킹 유실 방어 (쿠키리스 대응)**: 브라우저 쿠키 제한 및 광고 차단 프로그램(Ad-Block)으로 인해 광고 매체 픽셀에서 결제 데이터가 누수되는 현상 방지.
* **매체 매칭 품질(EMQ) 향상**: 단순 결제 신호만 보내는 것이 아니라 해시 처리된 유저 정보와 광고 클릭 식별자(`gclid`, `fbclid`)를 정밀하게 결합하여 매체의 타겟팅 최적화 효율 극대화.
* **시스템 부하 분산 및 안정성 확보**: 외부 결제 알림(Toss 웹훅) 수신 구조와 무거운 데이터 조회 및 매체 발송 로직을 비동기로 분리하여 시스템 안정성 확보.

---

## 🏗️ 시스템 데이터 흐름

```text
[토스 결제 완료 웹훅 발생]
               │
 [GCP 클라우드 수신 프로세서 가동]
  - 결제 완료(status == 'DONE') 건만 정밀 필터링 추출
               │
               ▼
 [데이터 안전 적재 (GCP Pub/Sub 큐)]
  - 대량 결제 유입 시 시스템 타임아웃 및 누수를 방지하기 위한 비동기 버퍼 구축
               │
               ▼
 [★ 핵심 데이터 결합 엔진 가동 (order-data-fetcher)]
  - AWS RDS (PostgreSQL): 유저 결제 원장 데이터 실시간 조인
  - GCP BigQuery: GTM 맞춤 변수(fbp, user_agent, user_ip) 및 클릭 식별자(gclid, fbclid) 결합
  - 개인정보 보안 암호화: 이메일, 전화번호 등 PII 데이터를 Meta 가이드라인에 맞춰 SHA256 해싱
               │
               ▼
 [다중 광고 매체 전송 체계 가동] ───► [최종 Meta CAPI 매칭 품질 8.1점 달성 🎉]
```

## 💡 프로젝트 주요 성과 및 강점

### 1. Meta 구매 이벤트 매칭 품질 (EMQ) 8.1점 달성
* GTM 맞춤 태깅과 BigQuery 추출기법을 정교하게 다듬어, Meta 이벤트 관리자 기준 **구매(Purchase) 이벤트의 매칭 품질 점수를 기존 5.6점에서 8.1점(우수)까지 상향**시켰습니다.
* 현재 데이터 누적 트렌드에 따라 실시간으로 모수가 최적화되고 있으며, 매체 머신러닝이 진성 결제 유저 세그먼트를 더 정확히 학습할 수 있는 기반을 마련했습니다.

### 2. GTM 수집 및 BigQuery 결합을 통한 고정밀 매칭 파라미터 확보
* 일반적인 자동 수집 방식으로는 유실되기 쉬운 브라우저 정보 및 매체 식별자를 확보하기 위해, **GTM(구글 태그 매니저)을 통해 유저 행동 데이터(`fbp`, `user_agent`, `user_ip`)를 직접 맞춤 변수로 선언하여 수집**했습니다.
* 이후 BigQuery에서 반복 구조(`UNNEST`)로 누적된 이벤트 파라미터들을 정밀하게 추출 및 조인하여, Meta CAPI 발송 시점에 높은 정합성을 지닌 고품질 유저 식별 데이터셋을 완성할 수 있었습니다.

### 3. 새로운 매체 추가가 유연한 구조 설계
* 메시지 큐 기반의 독립 발송 구조를 채택하여, 향후 틱톡이나 트위터 등 **새로운 광고 매체가 추가되더라도 기존의 결제 수신 및 데이터 결합 코드를 전혀 건드리지 않고**, 새 매체의 전송 코드만 독립적으로 추가 배포하면 되는 뛰어난 확장성을 확보했습니다.

### 4. 멀티 클라우드 데이터 실시간 결합 (`order-data-fetcher`)
* 실시간 결제 알림으로 들어오는 파편화된 데이터에 AWS의 구매 원장 데이터와 GCP의 행동 로그(광고 기여 식별값) 데이터를 밀리초(ms) 단위로 실시간 조인하여 마케팅 데이터 마트의 비즈니스 가치를 극대화했습니다.
* 민감할 수 있는 유저 정보는 매체별 컴플라이언스 기준에 일치하도록 정규표현식(Regex) 정제 후 `SHA256` 단방향 해싱 처리를 수행하여 정합성과 보안성을 동시에 확보했습니다.
