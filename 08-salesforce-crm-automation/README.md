# 🚀 공유오피스 1인실 드랍 유저 CRM 문자 자동 발송 시스템

세일즈포스의 드랍 고객 데이터를 기반으로 구글 시트의 CRM 메시지 템플릿을 매핑하여, 솔라피를 통해 개인화된 LMS 문자를 자동 발송하고 발송 로그를 관리하는 데이터 파이프라인 시스템입니다.

---

## 🛠 기술 스택 (Tech Stack)

| 분류 | 기술 및 서비스 | 주요 역할 |
| :--- | :--- | :--- |
| **Data Source** | Salesforce | 공유오피스 1인실 드랍(Drop) 고객 리드 데이터 추출 |
| **Orchestrator** | GCP Vertex AI (Python) | 데이터 전처리, 시간대 변환, 사유 매핑 및 API 연동 총괄 |
| **Storage & Auth** | Google Cloud Storage (GCS) | 구글 API 인증에 필요한 서비스 계정 Key 관리 |
| **CRM Template** | Google Sheets | 마케팅 메시지 템플릿 관리 및 최종 발송 결과 백업 |
| **Messaging API** | Solapi | HMAC-SHA256 시그니처 인증 기반 대량 LMS 문자 발송 |
| **Data Warehouse** | Google BigQuery (준비 중) | 최종 발송 로그 및 Raw 데이터 적재 (Data Lake) |

---

## 🔄 시스템 데이터 흐름 (Data Flow)

### 1. 인증 및 CRM 템플릿 로드
* **GCS 키 인증**: Google Cloud Storage에 안전하게 보관된 JSON 서비스 계정 키를 읽어와 Google Sheets API 권한을 인증합니다.
* **매트릭스 파싱**: 구글 스프레드시트에 세로형 매트릭스로 정리된 CRM 메시지 셋트(드랍 사유, 시점, 제목, 본문)를 Pandas 데이터프레임으로 파싱합니다.

### 2. 세일즈포스 대상자 추출
* **조건별 리드 조회**: `simple-salesforce` API를 통해 **공유오피스 / Drop 상태 / 희망 인원 1인** 조건에 맞는 유저 리스트를 실시간으로 가져옵니다.

### 3. Vertex AI (Python) 중심의 데이터 가공
* **한국 시간(KST) 변환**: UTC 타임존으로 저장된 세일즈포스의 생성일/수정일을 국내 비즈니스 시간에 맞게 KST(+09:00)로 정렬합니다.
* **전일 대상자 필터링**: 날짜 단위 비교 연산을 통해 오직 **'어제' 드랍된 고객(Drop+1 시점)** 47건만 정교하게 걸러냅니다.
* **사유 재분류 및 조건 매핑**: 상세 드랍 사유를 규칙에 따라 '비상주', '예산 초과', '그 외' 3가지 카테고리로 맵핑한 후 구글 시트 템플릿과 Left Join 합니다.

### 4. 솔라피(Solapi) 활용 LMS 발송
* **전화번호 정제**: 수신자 번호에서 하이픈(-)과 특수문자를 제거하여 숫자만 추출합니다.
* **보안 인증 발송**: 대량 발송 규격에 맞춰 페이로드를 구성한 뒤, 내부 보안 가이드라인(HMAC-SHA256 시그니처 생성)을 준수하여 솔라피 API로 문자를 안전하게 전송합니다.
* **안전한 검수 환경**: 실제 고객 오발송을 방지하기 위해 고유 시나리오별로 테스트 담당자 정보로 오버라이드하여 사전 검수하는 방어 로직이 포함되어 있습니다.

### 5. 결과 기록 및 로그 백업
* **구글 시트 백업**: 당일 매핑 및 발송 처리가 완료된 `yesterday` 데이터는 스프레드시트의 전용 탭에 실시간으로 업데이트하여 마케팅팀이 모니터링할 수 있도록 합니다.
* **BigQuery 적재 가공 완료**: 로그 추적용 필수 컬럼과 발송 시각(`SentAt`)을 추가하고 문자열(String) 형태로 타입을 일치시켜 빅쿼리에 즉시 적재할 수 있도록 준비해 둔 상태입니다.
